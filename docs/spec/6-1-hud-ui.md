# 6-1 HUD, Tech Tree UI & Overlays

## Prompt

Build the essential 2D UI layer on top of the 3D canvas: top bar showing stars, turn number, and current player; a tech tree panel; unit info card; and end-turn button. Use HTML overlays via `@react-three/drei` `<Html>` or a separate React DOM layer. Keep the UI readable on both desktop and mobile.

## Supplementary Information

- Prefer a clean, high-contrast design matching the geometric Polytopia aesthetic.
- Tech tree can be a simple modal or side panel for the first version.
- Acceptance: Player can see resources, open the tech tree, research, and end turn entirely through the UI.
